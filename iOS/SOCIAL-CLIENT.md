# iOS 好友、聊天与邀请

iOS 与 Mac 使用同一个已部署的 MC Harbor Friends 服务。安装包仅附带公开服务地址，玩家无需部署或填写服务器。首次在好友页创建昵称，或主动导入已有身份的恢复密钥；好友身份与 Minecraft 登录分开。

## 已接入

- 双向申请、接受 / 拒绝、移除好友、昵称 / 备注 / 好友码搜索。备注按身份保存在本机，恢复另一身份不会覆盖前一身份的备注文件。
- 默认 Steve 头像；对方共享皮肤时读取授权 PNG，并从真正的皮肤头部与帽子层生成头像。读取前检查大小和64×64 / 64×32尺寸，再解码，避免畸形大图造成内存激增。皮肤可从 Files 选取并共享，也可撤销。
- 读取对方主动共享的最近游戏：实例、Minecraft 与加载器、存档、时长及同行信息。可筛选与自己一起的记录；同行由玩家选择，不代表自动确认处于同一服务器。
- 好友聊天、未读、重连、前后台生命周期，以及30分钟有效的服务器邀请。重试保持消息 UUID，防止网络超时后重复发送。消息默认保留30天，客户端显示最近100条。
- iOS 进入后台关闭 WebSocket / 心跳与备用刷新；回到前台重连。实时不可用时只在前台定期认证刷新。恢复密钥使用独立 iOS Keychain 项，不上传游戏令牌；显式复制密钥仅写本机剪贴板并设一分钟过期。
- HTTP 认证请求拒绝跨源重定向，WebSocket 的密钥在 Authorization 头中，不放查询参数。好友移除、停止共享与皮肤变更时清理相应界面缓存。

## 验证与剩余范围

`tools/test-social-client.py` 使用生产 Swift 客户端与现有 Python 生产服务，在本机临时数据库建立三个隔离身份，实际检查双向好友、非好友拒绝、幂等消息、邀请、未读、历史、皮肤、撤权与身份删除。另一 HTTP 源没有收到任何重定向请求或凭证。没有在公共服务注册测试账号。

`SocialTests.swift` 检查48好友、身份重复、地址 / 恢复密钥注入、消息长度、过期、皮肤解码前尺寸、游戏时长等边界。UI 宿主仅在明确的 `HARBOR_FRIENDS_FIXTURE=1` 下通过依赖注入读取48名隔离好友，验证列表与备注，不将夹具当成线上或游戏实玩证据。完整原生 App 使用实际公开服务，未加入夹具开关。

本轮只读检查 `/health` 返回200，chat/realtime均为true。公共服务可用性受网络和 Cloudflare 免费计划配额限制，不承诺第三方永久无限免费。

iOS 自身会话记录已连接原生游戏界面的出现与退出事件。使用 systemUptime 记录前台时长，进入后台暂停，每30秒原子保存；强退后只保留最后检查点，不把离线时间算作游玩。默认仅保存在本机，开启共享后才增量上传变化记录，每批最多25条。未检测到的存档名称留空，不推测玩家进入的世界。6项真实文件检查覆盖暂停、重复进入、切换实例、重启、损坏数据、链接和写入失败回滚；原生游戏事件与实际游玩仍单独验收。

服务器地址邀请可以读取和复制；iOS 不能直接运行桌面的 Terracotta / EasyTier 或 Sakura FRP 进程。实际穿透涉及网络扩展、签名和设备授权，不能用一个外观按钮假装完成。游戏渲染、JIT、登录与一键加入必须分别验收，完整状态见 PORTING.md。
