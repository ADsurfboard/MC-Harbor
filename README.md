# MC Harbor

为 Mac 而生的 Minecraft 启动器。

**1.4.0 · Apple Silicon · macOS 26 及以上**

[下载最新版本](https://github.com/ADsurfboard/MC-Harbor/releases/latest) · [阅读 PDF 介绍](docs/MC-Harbor-启动器介绍.pdf) · [构建与许可](BUILDING.md) · [反馈问题与建议](https://github.com/ADsurfboard/MC-Harbor/issues)

以下内容来自随软件附带的《MC Harbor 启动器介绍》PDF。完整 PDF 与本仓库同时保留。

原生，清晰，随手可用。保留 HMCL 的游戏能力，采用 WinHarbor 原生界面，把账号、下载、实例资源与汉化工作集中在一个窗口。

## 日常操作，一处完成。

以实例为中心。保留加载器原图标、可视化资源管理与明确的下载目标。

### 游戏库

搜索、收藏、显示名称、加载器识别、实例设置、启动与依赖修复。实例可更换图标，也可恢复原图标。

### 实例资源

模组、资源包、光影、地图等统称实例资源。原图标优先；支持多选、启停、本地导入与打开原项目页面。

### 下载中心

联动 Modrinth 与 CurseForge。搜索模组、资源包、光影、地图和整合包，筛选兼容版本与加载器，解析必要依赖并校验文件。

### 账号与角色

导入原 HMCL 账号；Microsoft、第三方认证、离线身份。真实皮肤头部头像、开源 3D 预览、导入皮肤并按身份能力应用。

### 外观与声音

主题调色盘、图片 / 视频背景、三层磨砂叠片、-100 至 +100 通透度、可关闭的局部彩虹色散。弹层过渡、欢迎动画、原音播报与界面音效。

### 存档与前置补全

原生编辑模式、天数、经验和生命等状态。可选前置补全在启动前检测并补齐必需模组；另有存档备份与便携模式。操作细节：实例更多按钮扩大为 38pt 圆形；按钮命中覆盖完整外形与内边距。下载搜索结果按整个圆角矩形选择，空白部分也可点击。

## 让汉化成为原生工作流。

读取原文、筛选范围、对照编辑、导出资源包。整个流程保留原实例资源。

### 读取全部 lang

扫描本体、已下载原版语言资产、模组 / 资源包与 KubeJS、resources 语言目录。保留所有语言原文件，原文与中文按命名空间和语言键对应。

### 选择全部或部分资源

左侧列表显示语言数量与翻译进度。可全选、清空或逐项勾选，也能搜索语言键、原文和译文，单独查看待翻译项。

### 社区补全与逐条编辑

一键按版本 / 加载器读取 CFPA 社区译库，校验 MD5 后补齐可用译文。已有中文和手动译文保留；未覆盖内容明确计为待翻译。

### 命名并导出汉化资源包

自定义名称，格式号优先读取实际游戏 JAR，兼容 JSON 与旧 LANG。保存 / 导入时检查 %s、%1$s、{0} 等占位符，导出附元数据与社区署名。

### 提取给 AI，再导回

未汉化包包含英文 zh_cn 模板、全部原始 lang、语言键目录与说明。让 AI 翻译模板值，保留键与占位符，再将同结构 ZIP 导入。工作区自动保存编辑草稿。译库不覆盖所有实例资源；当前版本没有内置付费 AI 账号或云翻译密钥。导出的社区译文遵循 CC BY-NC-SA 4.0，已附许可与项目来源。

## 任务与数据包，也能汉化。

同一工作区继续深入 FTB Quests 与存档数据包，按原结构提取与应用显示文本。

### FTB Quests 的核心文本

读取章节与章节组标题、任务标题 / 副标题 / 说明、任务与奖励的自定义标题，以及章节图片悬浮说明。支持旧版内联 SNBT、中期 lang/en_us.snbt 和新版按章节拆分的 JSON5 语言文件；已有中文与额外语言键保留。

### 存档数据包与书页

自动发现 saves/<世界>/datapacks 中的 ZIP 和文件夹，以及实例 datapacks。提取进度的标题 / 说明、Patchouli 书页，以及 tellraw 和 title 指令的文字组件，覆盖聊天、标题与动作栏显示。只处理识别出的文本，任务 ID、物品 ID、触发条件与指令结构保留。

### 一套编辑与 AI 导回流程

任务和数据包同样支持全部 / 部分选择、原文对照、逐条编辑和草稿重读。提取给 AI 会保留原始 SNBT /JSON5 / 数据文件，并提供带映射键的未汉化模板；翻译后用导入译文接回。颜色代码、格式占位符与物品链接等标记会校验。

### 资源包与任务补丁分开应用

普通 lang 导出为资源包；任务配置与数据包译文使用“应用任务 / 数据包”。先检查文件修订和存档占用，再保存原字节备份、校验 ZIP 并原子写回，失败回滚。导出的 ZIP 也包含 overrides 目录，可按实例根目录合并；原 JAR 不改写。自写 FTB 任务通常没有现成社区译文，未覆盖的内容会保持待翻译，需手工编辑或交给 AI。新增流程已完成 39 项隔离协议检查并完整复跑，包含中途写入失败的回滚；未替用户修改真实存档，也未冒称完成 FTB 游戏内全流程试玩。

## 编辑世界，补齐前置。

实例中的存档可直接编辑。需要时开启前置补全，把缺失检查放在游戏启动之前。

### 原生存档编辑

实例 → 存档 → 编辑。可修改存档名称、游戏模式、难度、作弊与极限选项；设置游戏天数、日内时间和世界累计时间。玩家状态包括生命、饱食度、饱和度、经验等级与进度，总经验联动计算。

### 先备份，再写回

支持本地玩家与独立 UUID 玩家文件。保存前检查 session.lock 和文件修订，自动保存本次涉及 NBT 文件的原字节 ZIP；保留背包、模组能力、未知标签与原数值类型。完整世界备份入口也保留。

### 前置补全，按需开启

设置 → 运行 → 前置补全，默认关闭。启用后先检查本地必需声明、Modrinth 与 CurseForge 的精确文件依赖，按游戏版本和加载器递归寻找前置；下载后校验哈希与真实模组 ID，全部准备完成再添加并启动游戏。

### 明确处理例外

内嵌前置与模组别名也算已安装，不重复补入。可选依赖不强装，停用项不擅自启用，冲突版本不覆盖。无法确认版本、下载受限或未公开的前置会说明缺失项并停止本次启动；可自行调整或关闭此开关。当前验证：25 项存档隔离检查、32 项前置图与事务检查，以及真实 Controlling → Searchables 下载 / 校验 / 重复检查通过。测试未改动玩家的真实存档与实例。

## 熟悉的内核，原生的外壳。

基于 HMCL 3.16.4 稳定内核与真实 WinHarbor SwiftUI / AppKit 代码进行适配。

### Swift / SwiftUI / AppKit

窗口、系统玻璃、导航、实例管理、偏好、动画与原生汉化编辑器。

### Java 17 字节码 / JDK 21

无窗口桥接 HMCL 认证、游戏依赖、下载、启动、元数据与语言文件处理。

### JavaScript / Three.js

本地离线 skinview3d 角色与披风渲染；使用真实 Minecraft 皮肤 UV。

### Python / Swift 工具

构建、封装、校验、ICNS 尺寸生成、交付检查与本介绍 PDF。原生界面JSON LinesHMCL 内核SwiftUI / AppKit按需启动任务进程认证 · 下载 · 游戏启动

### 数据与账号

接入原 HMCL 游戏目录，避免复制产生两套存档。账号身份元数据与凭据分开，完整会话存入当前 Mac 的Keychain；3D 皮肤网页只接收图像，不接收凭据。

### 兼容与便携

默认数据目录沿用 ~/Library/Application Support/ShengganLauncher，以兼容已有设置。应用旁放MCHarbor.portable 后使用旁边的 MCHarborData；原 HMCL JAR 保持不变。

### 性能策略

Java 任务按需启动；原壁纸和缩略图按文件修订缓存，资源索引批量发布，语言表后台解码，视频与流体只在状态变化时更新。既有声音、皮肤、叠片、粒子和正区间系统玻璃保留；负区间磨砂增加背景扩散，不加深颜色。
