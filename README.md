为 macOS 重新设计的 Minecraft 启动器。
保留 HMCL 的游戏能力，采用真实 WinHarbor 原生界面，
把账号、下载、实例资源与汉化工作集中在一个窗口。

1.5.2 Intel 兼容版 · macOS 12 及以上
验证：Intel macOS 15 自动测试与 Rosetta 检查

## 日常操作，一处完成。

以实例为中心。默认加载器图标高清重绘，保留实例资源原图标、可视化资源管理与明确的下载目标。

### 游戏库

搜索、收藏、实例设置和依赖修复。支持更换图标；删除前检查版本依赖并移入废纸篓。

### 实例资源

模组、资源包、光影、地图等统称实例资源。原图标优先；支持多选、启停、本地导入与打开原项目页面。

### 下载中心

联动 Modrinth 与 CurseForge。搜索实例资源；游戏和模组加载器默认优先使用国内镜像，并可切换下载来源。

### 账号与角色

导入原 HMCL 账号；支持 Microsoft、离线及自定义 authlib-injector API 外置登录。真实皮肤头像与 3D 预览。

### 外观与声音

主题调色盘、图片 / 视频背景、三层叠片、0 至 100 通透度与独立深浅毛玻璃选项、可关闭的局部彩虹色散。弹层过渡、欢迎动画、四种原音播报与界面音效。

### 存档与前置补全

原生编辑模式、天数、经验和生命等状态。可选前置补全在启动前检测并补齐必需模组；另有存档备份与便携模式。

操作细节：实例更多按钮扩大为 38pt 圆形；按钮命中覆盖完整外形与内边距。下载搜索结果按整个圆角矩形选择，空白部分也可点击。

## 让汉化成为原生工作流。

读取原文、筛选范围、对照编辑、导出资源包。整个流程保留原实例资源。

### 读取全部 lang

扫描本体、已下载原版语言资产、模组 / 资源包与 KubeJS、resources 语言目录。保留所有语言原文件，原文与中文按命名空间和语言键对应。

### 选择全部或部分资源

左侧列表显示语言数量与翻译进度。可全选、清空或逐项勾选，也能搜索语言键、原文和译文，单独查看待翻译项。

### 社区补全与逐条编辑

一键按版本 / 加载器读取 CFPA 社区译库，校验 MD5 后补齐可用译文。已有中文和手动译文保留；未覆盖的英语原文可由系统或经确认的在线引擎补齐；无法安全处理的条目标记待翻译。

### 命名并导出汉化资源包

自定义名称，格式号优先读取实际游戏 JAR，兼容 JSON 与旧 LANG。保存 / 导入时检查 %s、%1$s、{0} 等占位符，导出附元数据与社区署名。

### 提取给 AI，再导回

未汉化包包含英文 zh_cn 模板、全部原始 lang、语言键目录与说明。让 AI 翻译模板值，保留键与占位符，再将同结构 ZIP 导入。

工作区自动保存编辑草稿。译库不覆盖所有实例资源；当前版本没有内置付费 AI 账号或云翻译密钥。导出的社区译文遵循 CC BY-NC-SA 4.0，已附许可与项目来源。

## 任务与数据包，也能汉化。

同一工作区继续深入 FTB Quests 与存档数据包，按原结构提取与应用显示文本。

### FTB Quests 的核心文本

读取章节与章节组标题、任务标题 / 副标题 / 说明、任务与奖励的自定义标题，以及章节图片悬浮说明。支持旧版内联 SNBT、中期 lang/en_us.snbt 和新版按章节拆分的 JSON5 语言文件；已有中文与额外语言键保留。

### 存档数据包与书页

自动发现 saves/<世界>/datapacks 中的 ZIP 和文件夹，以及实例 datapacks。提取进度的标题 / 说明、Patchouli 书页，以及 tellraw 和 title 指令的文字组件，覆盖聊天、标题与动作栏显示。只处理识别出的文本，任务 ID、物品 ID、触发条件与指令结构保留。

### 一套编辑与 AI 导回流程

任务和数据包同样支持全部 / 部分选择、原文对照、逐条编辑和草稿重读。提取给 AI 会保留原始 SNBT / JSON5 / 数据文件，并提供带映射键的未汉化模板；翻译后用导入译文接回。颜色代码、格式占位符与物品链接等标记会校验。

### 资源包与任务补丁分开应用

普通 lang 导出为资源包；任务配置与数据包译文使用“应用任务 / 数据包”。先检查文件修订和存档占用，再保存原字节备份、校验 ZIP 并原子写回，失败回滚。导出的 ZIP 也包含 overrides 目录，可按实例根目录合并；原 JAR 不改写。

自写 FTB 任务通常没有现成社区译文。macOS 15 及以上可用系统翻译；12—14 可选择在线补全，也可逐条校对或提取给 AI。旧版的 39 项隔离检查包含写入失败回滚；未替用户修改真实存档。

## 编辑世界，补齐前置。

实例中的存档可直接编辑。需要时开启前置补全，把缺失检查放在游戏启动之前。

### 原生存档编辑

实例 → 存档 → 编辑。可修改存档名称、游戏模式、难度、作弊与极限选项；设置游戏天数、日内时间和世界累计时间。玩家状态包括生命、饱食度、饱和度、经验等级与进度，总经验联动计算。

### 先备份，再写回

支持本地玩家与独立 UUID 玩家文件。保存前检查 session.lock 和文件修订，自动保存本次涉及 NBT 文件的原字节 ZIP；保留背包、模组能力、未知标签与原数值类型。完整世界备份入口也保留。

### 前置补全，按需开启

设置 → 运行 → 前置补全，默认关闭。启用后先检查本地必需声明、Modrinth 与 CurseForge 的精确文件依赖，按游戏版本和加载器递归寻找前置；下载后校验哈希与真实模组 ID，全部准备完成再添加并启动游戏。

### 明确处理例外

内嵌前置与模组别名也算已安装，不重复补入。可选依赖不强装，停用项不擅自启用，冲突版本不覆盖。无法确认版本、下载受限或未公开的前置会说明缺失项并停止本次启动；可自行调整或关闭此开关。

当前验证：25 项存档隔离检查、32 项前置图与事务检查，以及真实 Controlling → Searchables 下载 / 校验 / 重复检查通过。测试未改动玩家的真实存档与实例。

## 熟悉的内核，原生的外壳。

基于 HMCL 3.16.4 稳定内核与真实 WinHarbor SwiftUI / AppKit 代码进行适配。

### Swift / SwiftUI / AppKit

窗口、原生磨砂、导航、实例管理、偏好、动画与原生汉化编辑器。

### Java 17 字节码 / JDK 21

无窗口桥接 HMCL 认证、游戏依赖、下载、启动、元数据与语言文件处理。

### JavaScript / Three.js

本地离线 skinview3d 角色与披风渲染；使用真实 Minecraft 皮肤 UV。

### JavaScript / SQL / Python

Cloudflare Workers、SQLite Durable Objects 与 D1 提供内置好友和实时聊天；Python / SQLite 自建版随源码提供。

### 数据与账号

接入原 HMCL 游戏目录，避免复制产生两套存档。账号身份元数据与凭据分开，完整会话存入当前 Mac 的 Keychain；3D 皮肤网页只接收图像，不接收凭据。

### 兼容与便携

默认数据目录沿用 ~/Library/Application Support/ShengganLauncher，以兼容已有设置。应用旁放 MCHarbor.portable 后使用旁边的 MCHarborData；原 HMCL JAR 保持不变。

### 性能策略

Java 任务按需启动；原壁纸和缩略图按文件修订缓存，资源索引批量发布，语言表后台解码，视频与流体只在状态变化时更新。保留既有视听效果；通透度为 0 至 100 的单调范围，毛玻璃使用独立原生背景扩散材质，分别适配深浅色。

## 更完整的汉化，更顺手的素材库。

Intel 版保留三层叠片、粒子、音效和原始 Clara 播报，用系统磨砂替代 Liquid Glass。

### 一键汉化：社区优先，再补齐

先使用 CFPA 社区中文；macOS 15 及以上可继续调用系统 Translation。macOS 12—14 可经确认使用 MyMemory 在线补全，每日有 5000 字符免费额度；系统翻译不可用时也可选择该回退。未完成的条目保留，支持手动校对或提取给 AI。

### 长段落与文本格式保护

长任务说明按词边界拆分，格式占位符、颜色代码、物品 / 任务链接和网址留在翻译引擎之外，写回前继续校验。保留已有中文与手动译文，拒绝写入原文已经改变的旧结果；可停止任务并保留完成部分。对照编辑区支持上下拖动、隐藏 / 再显示，并记住高度与显示状态。

### LittleSkin 原生皮肤库

在账号页搜索公共皮肤、按收藏或最新排序、翻页、收藏与打开作者原网页。标准皮肤下载后验证 SHA256 与 PNG 尺寸，用现有 skinview3d 渲染真实 Minecraft 三维角色。确认后应用到所选账号；在线上传仍取决于该账号服务能力。高清皮肤会明确提示标准账号尺寸要求。

### 命名、预览、切换壁纸

壁纸库支持批量导入图片 / 视频，逐张命名、预览和切换。视频缩略图右下角显示视频标记，预览默认静音；原有背景登记到库中。新导入内容使用受管理的副本，移除不会删除原始文件。

七个默认游戏 / 加载器图标已用 imagegen 重绘成高清透明素材；自定义实例图标与实例资源自带图标继续优先。浅色界面使用黑色折面 h，深色界面保留白色 h。实例设置新增文件大小与磁盘分配空间统计，跳过符号链接并对硬链接去重；APFS 共享块以文件系统分配统计为准。

## 好友与聊天，已经连通。

默认内置公共服务。玩家无需创建 Cloudflare 账号、部署数据库或填写服务地址。

### 好友身份与多好友列表

首次打开好友页，设置昵称并创建好友身份，交换好友码、双方确认后成为好友。支持接受 / 拒绝、移除、搜索昵称 / 备注 / 好友码；列表独立滚动，长昵称自动省略，备注只存本机。24 个测试好友已检查消息、头像与历史隔离。

### 皮肤头像与最近游戏

共享的标准皮肤生成真实 Minecraft 头部头像，并可预览三维角色。主动开启共享后，好友可查看最近实例、整合包、版本、加载器、最近修改的存档目录名与时长。可筛选与特定好友的记录；同行由玩家选择，不自动推断双方已经进入同一服务器。

### 文字消息与联机邀请

内置聊天通过 HTTPS 发送、WebSocket 实时通知，断线退回安全刷新并恢复未读提示。每位好友各有会话与草稿，重试复用消息编号避免重复发送。可发送陶瓦房间码、已开启的 Sakura 地址或普通服务器地址；收到后打开联机入口，邀请 30 分钟有效。

### 共享、恢复与保存范围

皮肤和最近游戏默认不共享，随时可撤销；移除好友后服务撤销历史、皮肤与聊天访问。消息保留 30 天，当前显示最近 100 条，服务端可处理明文，并非端到端加密。游戏登录令牌、文件、私有路径和本机备注不会上传。恢复密钥单独导出，换 Mac 可恢复同一好友身份。

默认服务由作者维护，当前使用 Cloudflare 免费 Workers + D1 + SQLite Durable Objects。玩家无需购买服务器；第三方额度与持续运营仍有边界，不能承诺永久无限容量。服务端及迁移配置开源，可按需自建，正常玩家不需要配置。

## 跨启动器，按标准联机。

陶瓦房间码与 Sakura Frp 两条路径；Minecraft 服务器地址不绑定启动器品牌。

### 标准地址，没有启动器品牌门槛

联机页填写服务器地址、选择兼容实例，可启动并直接加入。复制地址后，使用其他启动器的朋友也能加入同一服务器。游戏版本、模组配置、服务器认证与外部服务额度仍然适用，启动器不承诺绕过这些条件。

### Sakura Frp：创建并开启 TCP 隧道

先在游戏中对局域网开放，再填写或从近期日志读取端口，选择节点并创建 TCP 隧道。官方 Intel frpc 按需下载、校验大小和 MD5；访问密钥保存在钥匙串，运行配置为私有权限文件，停止时删除。确认隧道成功后才显示可复制的地址。公开服务器模式只列服务允许的节点。

### 陶瓦房间：无需配置中转服务器

基于官方 Terracotta / EasyTier 模块，优先 P2P，按需从官方发布页下载并验证 SHA256。macOS 直接运行官方进程、读取本机端口并管理生命周期，无需安装系统后台服务。先进入存档、开放局域网，再创建房间；朋友通过支持陶瓦的启动器或独立客户端加入。

### 使用边界

好友聊天不需要玩家部署服务。陶瓦使用社区公共节点，NAT、网络质量和节点状态会影响连通；Sakura 需要玩家自己的访问密钥、可用节点及相应额度。普通地址可用于其他启动器，但 Minecraft 版本、模组配置和服务器认证仍须匹配，不绕过正版或服务器权限。

Intel 版已在 Rosetta 下校验并启动官方陶瓦、退出房间，并验证 Sakura Intel 客户端版本；其他陶瓦数据未被改动。没有宣称完成两台外网设备长时间 Minecraft 联机，也未使用真实 Sakura 账号建立测试隧道。新版本读取 Mojang 实时清单，失败时使用镜像与缓存；后续格式、认证或 Java 要求变化仍需维护适配。
