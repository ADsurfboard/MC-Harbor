# LauncherPK 功能标记

LauncherPK 使用人工维护的 data/launchers.js。MC Harbor 已提交修正：https://github.com/cnklpz/LauncherPK/pull/6 。

mirror 对应 NativeBridge.java 的 BMCLAPIDownloadProvider 与官方回退；authlib 对应自定义 authlib-injector / Yggdrasil 外置登录，包括 API 地址定位和多角色选择。外置登录有本地模拟服务回归，镜像已在隔离库实际安装 Forge / Fabric 验证。

标记提交不代表已经合并，也不会自动改变原站。上游合并并部署后，页面才会显示两个功能标签。
