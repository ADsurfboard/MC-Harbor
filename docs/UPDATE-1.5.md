# MC Harbor 1.5.0

更新日期：2026-10-26。原生 SwiftUI / AppKit 界面，沿用 HMCL 3.16.4 稳定内核，Apple Silicon / macOS 26+。

好友与聊天的公共 Workers / D1 / SQLite Durable Objects 服务已部署，默认地址内置。新增好友码、双方确认、皮肤头部头像、三维角色、备注、最近游戏、同行筛选、独立聊天 / 草稿、未读恢复和限时联机邀请。普通玩家无需自己部署服务器；测试与正式 App 的钥匙串身份隔离。

联机加入官方 Terracotta / EasyTier，按需校验下载，直接管理 macOS 官方 daemon 进程，无需安装系统后台服务。保留 Sakura Frp 原生操作和标准地址入口。Sakura 使用玩家自己的密钥与节点额度；其他启动器可使用相同标准地址或独立陶瓦客户端。未宣称所有 NAT / 网络永久无限连通。

一键汉化按社区译库优先，再用系统 Translation 补齐英语。范围包括 lang、KubeJS、FTB Quests 与已识别的存档数据包显示文本，保留格式标记与原文；支持部分选择、人工对照、AI 模板、导回与备份应用。编辑区可拖动、隐藏并记住状态，移除表头黑角。

新增 LittleSkin 皮肤库、命名与预览的图片 / 视频壁纸库、实例磁盘分配统计、七种高清默认图标和浅色黑 h。通透度改为 0—100，深浅毛玻璃独立开关，主题外观使用偏淡主题色并保证控件文字对比。保留旧粒子、叠片、转场、界面音效与原女声，另加 Adam 男声、Clara 女声 2、Morgan 男声 2 原录音。关于页增加作者 GitHub、B站和 Issues 入口。
