# 1.7.0 壁纸库与汇总发布验收

## 已定位的问题

用户的 macOS 27.0 / 26A428 崩溃记录显示：1.6.1 在主线程初始化 `_AVKit_SwiftUI` 的泛型父类元数据时触发 `SIGABRT`。1.6.2 的壁纸库沿用了相同 `VideoPlayer` 代码。这个故障发生在构建 SwiftUI 页面时，不能仅用图片导入、缩略图解码测试证明页面不会闪退。

壁纸库已统一改为 `NSViewRepresentable` 嵌入 AppKit `AVPlayerView`，避免实例化问题组件，保留原生播放控制、比例适配和静音预览。切换视频时暂停旧播放器，页面移除时暂停并解除播放器引用；不改变现有壁纸、账号或实例目录。

快捷方式另修复已运行启动器收到请求后，LaunchServices 激活回调偶尔不返回、辅助进程仍驻留的问题。交接按原私有收件目录的实际接收结果完成，并保留系统回调路径；测试同时要求冷 / 热启动准确分发一次、请求已消费及辅助进程正常退出。

## 分层检查

- `tools/check-wallpaper-preview.py`：把实际生产预览组件装入 SwiftUI；8 轮空白 / 图片分支、视频挂载、切换、关闭、播放器释放，以及真实视频解码、失效路径，共 58 项。在作者实际 macOS 27 设备上通过；该工具也在 Intel / Apple Actions 中运行。
- `tools/check-wallpaper-library.py`：使用生产 `WallpaperLibraryPanel` 与 `LauncherModel`，在临时数据目录挂载完整窗口。空库、图片、视频、失效图片和失效视频分别反复打开 / 关闭，检查预览类型与关闭后的播放状态，共 45 项。此层结果以对应提交的 CI 附件为准。
- 原有壁纸业务检查继续验证导入副本、原图字节、图片 / 视频缩略图、命名持久化、移除副本及保留原件；不以静态源码匹配代替运行。
- 原有账号、好友 / 聊天、发现、汉化流水线、实例删除、外置登录、窗口恢复和快捷方式回归保留。正式发布以当前提交的完整 Actions 通过为前提；历史失败记录保留。

## 发布与边界

Apple Silicon 与 Intel 共用一条正式 Release，分别提供对应 ZIP 与源码、统一介绍 PDF 和 SHA-256。声音、四份欢迎语音、图标及其他现有视觉效果保留。CI 的无音效测试构建仅为中间产物，正式交付必须恢复已有授权音效库并重新签名、校验。

Apple 版最低目标 macOS 26，Intel 版最低目标 macOS 12。自动检查所在系统与最低部署目标分别记录；macOS 12—14 实际硬件和所有整合包仍未穷尽验证，应用尚未 Apple 公证。

iOS / iPadOS 的完整 App 与工程回归位于独立分支，壁纸库尚未完成移植；Windows 原生移植由授权协作者负责。本次两份 macOS 安装包不冒充其他平台的正式成品。
