# Intel 兼容分支验证记录

目标是 Intel x86_64、macOS 12 及以上。界面使用 `NSVisualEffectView` 原生磨砂；较旧系统的滚动区域、选择菜单、文件拖放、多行聊天和延时任务有兼容实现。系统 Translation 只在 macOS 15 及以上使用，框架以弱链接方式加载；旧系统可以经明确确认使用有限额的在线回退。

本地实际环境：Apple Silicon、macOS 27，Rosetta 运行 x86_64 的 Swift 客户端、Intel Temurin 21 JVM、OpenJFX 本地库及官方 Intel 网络模块。它不是 macOS 12—14 实机测试。

| 验证 | 结果 | 范围 |
| --- | --- | --- |
| Intel Swift 客户端 | 53 项通过 | 临时账号与本地好友服务、聊天、邀请、真实皮肤头部、壁纸、空间统计、输入地址与格式保护；联网获取 LittleSkin 和 Intel Sakura 客户端并校验版本 |
| 多好友 | 16 项通过 | 新建 24 位合成好友和申请，检查独立未读、消息、草稿、头像、备注、历史、快速切换与移除 |
| Intel Java 后端 | 22 项通过 | 用打包的 Intel JVM 检查实例汉化、占位符、原文件保护、快捷加入与游戏时长回执 |
| 翻译与架构 | 分段 / 占位符 / 配额处理通过 | Intel 编译与 Rosetta 执行，MyMemory 以公开合成文本实际返回中文；不发送玩家资料 |
| 好友服务 | Worker 59 项、Python 45 项通过 | 使用本地隔离数据库，覆盖请求认证、撤权、消息、数据与多好友边界 |
| 陶瓦 Intel 核心 | 启动并退出通过 | 下载官方 x86_64 模块并校验发布哈希，进入扫描状态再退出；同时校验原有 `~/terracotta` 文件未改变 |
| Minecraft 版本清单 | 官方及镜像均返回 | 从 Intel Java 进程实际读取版本清单；不能据此保证未来第三方服务永久可用 |

本机 Apple Translation 状态为支持但语言模型未安装，因此没有在本次 Intel 测试中把系统翻译计作实测通过；首次使用可能要求系统下载模型。在线回退有匿名每日 5000 字符额度，达到额度或网络异常时保留已有译文，并可继续手动编辑或提取给 AI。

GitHub Actions 配置了 `macos-15-intel` 原生 x86_64 运行器，用于重新构建与运行客户端和后端测试；实际结果以该分支的 Actions 记录为准。该运行器不能代替 macOS 12—14 的实机检查。

Mac 锁屏使本轮界面目视验收无法进行。尚未覆盖：macOS 12—14 实机界面、全部整合包长时间游戏、两台外网设备长时间联机、真实 Sakura 账号隧道、所有旧显卡及 Apple 公证。这里的测试结果不能证明没有任何错误或安全漏洞。

## 1.5.2 Intel 修复

镜像优先、Yggdrasil API 自动定位与多角色登录、实例目录与继承关系校验分别提供独立回归：`tools/check-external-login.py`、`tools/check-instance-deletion.py`。`tools/check-loader-install.py` 可在隔离目录执行联网的加载器列表和完整安装检查；可用 `HARBOR_QA_SEED_ROOT` 只读克隆官方资源以减少下载。程序坞恢复及删除面板还需运行实际窗口检查。持续集成记录和发布说明列出各项实际结果；旧系统实机及第三方服务不可用时的情况仍不能由这些测试代替。
