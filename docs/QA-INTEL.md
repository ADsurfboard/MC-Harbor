# Intel 兼容分支验证记录

目标是 Intel x86_64、macOS 12 及以上。界面使用 `NSVisualEffectView` 原生磨砂；较旧系统的滚动区域、选择菜单、文件拖放、多行聊天和延时任务有兼容实现。系统 Translation 只在 macOS 15 及以上使用，框架以弱链接方式加载；旧系统可以经明确确认使用有限额的在线回退。

本地实际环境：Apple Silicon、macOS 27，Rosetta 运行 x86_64 的 Swift 客户端、Intel Temurin 21 JVM、OpenJFX 本地库及官方 Intel 网络模块。它不是 macOS 12—14 实机测试。

| 验证 | 结果 | 范围 |
| --- | --- | --- |
| Intel Swift 客户端 | 53 项通过 | 临时账号与本地好友服务、聊天、邀请、真实皮肤头部、壁纸、空间统计、输入地址与格式保护；联网获取 LittleSkin 和 Intel Sakura 客户端并校验版本 |
| 多好友 | 16 项通过 | 新建 24 位合成好友和申请，检查独立未读、消息、草稿、头像、备注、历史、快速切换与移除 |
| Intel Java 后端 | 22 项通过 | 用打包的 Intel JVM 检查实例汉化、占位符、原文件保护、快捷加入与游戏时长回执 |
| 翻译与架构 | 分段 / 占位符 / 配额处理通过 | Intel 编译与 Rosetta 执行，MyMemory 以公开合成文本实际返回中文；不发送玩家资料 |
| 好友服务 | Worker 59 项、Python 45 项通过 | 使用本地隔离数据库，覆盖请求认证、撤权、消息、数据与多好友边界 |
| 陶瓦 Intel 核心 | 启动并退出通过 | 下载官方 x86_64 模块并校验发布哈希，进入扫描状态再退出；同时校验原有 `~/terracotta` 文件未改变 |

本机 Apple Translation 状态为支持但语言模型未安装，因此没有在本次 Intel 测试中把系统翻译计作实测通过；首次使用可能要求系统下载模型。在线回退有匿名每日 5000 字符额度，达到额度或网络异常时保留已有译文，并可继续手动编辑或提取给 AI。

GitHub Actions 配置了 `macos-15-intel` 原生 x86_64 运行器，用于重新构建与运行客户端和后端测试；实际结果以该分支的 Actions 记录为准。该运行器不能代替 macOS 12—14 的实机检查。

早期验证曾因 Mac 锁屏未完成目视检查；1.5.3 已补做隔离界面和真实模组安装检查。尚未覆盖：macOS 12—14 实机界面、全部整合包长时间游戏、两台外网设备长时间联机、真实 Sakura 账号隧道、所有旧显卡及 Apple 公证。这里的测试结果不能证明没有任何错误或安全漏洞。

## 1.5.2 Intel 修复

镜像优先、Yggdrasil API 自动定位与多角色登录、实例目录与继承关系校验分别提供独立回归：`tools/check-external-login.py`、`tools/check-instance-deletion.py`。`tools/check-loader-install.py` 可在隔离目录执行联网的加载器列表和完整安装检查；可用 `HARBOR_QA_SEED_ROOT` 只读克隆官方资源以减少下载。程序坞恢复及删除面板还需运行实际窗口检查。持续集成记录和发布说明列出各项实际结果；旧系统实机及第三方服务不可用时的情况仍不能由这些测试代替。

## 1.5.3 Intel 窗口恢复与下载体验

- 窗口接入改为 NSView 挂载时注册，保留 SwiftUI 的 scene 标识。标准重新打开 AppleEvent 单独恢复原窗口，解除最小化并取消隐藏，避免创建空白窗口。
- 本机以 x86_64、macOS 12 最低目标编译的生命周期测试通过 25 项：三轮最小化、三轮关闭、隐藏恢复及不重复窗口。当前 Mac 为 Apple 芯片，运行 Intel 二进制使用 Rosetta；macOS 12–14 的实机界面尚未验证。
- 推荐模组仅显示 Modrinth 返回当前 Minecraft 版本和加载器兼容文件的项目，并提供用途说明、已安装标记与完整安装计划。推荐不等同于任意模组组合均无冲突。
- 中英文搜索：常用中文名称本地映射；其他中文关键词在线转换为英文。简介自动译文默认开启，支持关闭、缓存和查看原文。服务不可用或免费额度耗尽时保留原文，中文搜索可使用英文名称重试。
- 实例快捷方式为 macOS `.webloc` 文件，通过本机登记的随机标识定位实例；未知标识、改写查询和非当前游戏库会拒绝。请先将最新版启动器放入应用程序并打开一次，注册快捷方式协议。
- 窗口恢复方法参照 [Apple AppKit reopen 事件文档](https://developer.apple.com/documentation/appkit/nsapplicationdelegate/applicationshouldhandlereopen(_:hasvisiblewindows:))；推荐版本元数据来自 Modrinth 官方 API。

新增检查结果：离线发现与快捷方式 14 项、Modrinth / MyMemory 真实接口 31 项通过。隔离界面实际完成推荐 Sodium 的安装，任务显示“安装完成”。

主题新增十类作用范围、四种反色模式及自动对比度保护；彩虹角、Metal 描边与开关已从生产代码删除。模组备注和主题范围为作者本轮新增需求，不计入 jiekee❄ 的反馈贡献。

最终新增离线回归 77 项通过，包含多来源备注隔离、多列表与重启持久化、六组主题色在深浅模式下的文字/按钮对比、自定义色和反色的 sRGB 往返。四份欢迎录音的字节一致性、Intel JVM/JavaFX 与严格签名检查通过。

追加回归包括 8 页共 240 条缓存简介、备用翻译响应、下载超时重试、损坏文件切源与 HTTPS 校验、运行中等待 / 退出继续 / 取消，以及 Intel 表格 56pt 最小行高。下载不再因实例运行而被禁用；安装提交仍等待游戏退出。

最终联网发现回归 92 项通过，使用真实 Modrinth 搜索第 1—8 页并分别翻译句式简介；纯标签保留原文，不将其误报为接口失败。隔离界面已验证中文备注保存 / 搜索、开始下载提示与跳转任务，并实际下载校验和安装 Fabric API 成功。

浅色设置界面补充目视检查：原生下拉框使用经过对比度保护的控件色，去除根视图对 secondary 语义材质色的覆盖，避免文字和边框直接使用过浅主题色。

原生 Intel CI 补获延迟激活通知触发的关闭竞态。已去除应用激活时无条件唤回窗口的备用观察器；保留标准 reopen Apple Event、应用代理和“显示主窗口”菜单。三轮关闭均新增延迟激活后仍保持隐藏的断言，生命周期检查共 25 项。CI 先构建优化发布客户端，独立功能检查执行非优化测试驱动以减少重复编译时间。

安装占用标记按任务隔离，取消另一个任务不会清除当前提交的标记；地图导入也阻止同一目录在写入期间启动。新增两个所有权回归断言。

最终关闭策略使用转发原委托回调的 NSWindowDelegate 代理拦截 windowShouldClose；红色按钮与 performClose 都只隐藏，保留 SwiftUI 场景。独立检查显式完成 NSApplication 启动并等待 AppKit 事件，覆盖空委托注册、原委托 resize 回调转发与快捷关闭，共 25 项本地通过。

独立窗口检查使用 NSApplication.run 主循环和主线程异步等待，让原生标题栏动作在正常 AppKit 事件分派下执行；不再靠嵌套 RunLoop 模拟应用运行。全部 25 项断言保留。
