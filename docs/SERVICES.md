# 好友、聊天与联机服务

默认服务已随 1.5.0 内置。玩家打开好友页，设置昵称并创建好友身份，交换好友码、双方确认即可使用；不需要 Cloudflare 账号、服务器、数据库或服务地址。好友身份与 Minecraft 游戏登录账号相互独立，加入需要正版认证的服务器仍使用自己的有效游戏身份。

## 谁在运行服务器

作者账号中的 Cloudflare Workers 接收好友、共享记录与消息；D1 保存资料和有限期消息；每个身份的 SQLite Durable Object 提供休眠式 WebSocket 通知。实时对象只转发消息类型与好友 ID，消息内容经受保护的 HTTPS 接口读取。默认公开地址是 `Assets/Services.json` 中的 `friends`。作者无需让自己的 Mac 常开。

目前部署使用免费计划，没有启用付费扩容。当前官方免费额度：Workers 每日 10 万请求；D1 每日约 500 万行读取、10 万行写入、总计 5GB 存储；SQLite Durable Objects 每日 10 万请求及 13,000 GB-s。额度为共享总量，不是每位玩家各有一份。达到限制或第三方服务异常时会暂不可用，不能保证第三方永久提供无限容量。当前部署不会向玩家自动收费。

依据：[Workers](https://developers.cloudflare.com/workers/platform/pricing/)、[D1](https://developers.cloudflare.com/d1/platform/pricing/)、[SQLite Durable Objects](https://developers.cloudflare.com/durable-objects/platform/pricing/)。核对日期为 2026-10-26。

## 共享与聊天

皮肤与游戏历史默认不共享，可分别选择共享和撤销。好友必须双方确认；移除关系后，服务拒绝皮肤、历史和聊天请求，聊天记录随关系删除。本机备注、私有路径、Minecraft 登录凭据和游戏文件不上传。游戏记录只包括实例 / 整合包名称、版本、加载器、最近修改的存档目录名、时长与玩家选择的同行好友。同行选择不是自动检测同一服务器；无法凭记录证明对方实际在线。

聊天为 HTTPS 传输和访问控制，不是端到端加密，服务运营方可处理明文。消息最多 2000 个 UTF-16 单元，当前显示最近 100 条，普通消息保存 30 天，邀请 30 分钟有效。定时清理已过期消息；过期消息即使尚未被清理也不会返回。WebSocket 断开后重连，暂不可用时在聊天页活动期间以低频安全刷新回退。收件摘要不包含聊天正文，可在重启后恢复未读提示；阅读进度和草稿保留在当前客户端范围。

每个 IP 每小时最多创建 8 个身份，接口与发信另有限流，每个身份最多 300 个好友关系 / 申请。恢复密钥等同好友身份凭据，储存在当前 Mac 钥匙串；公开好友码不含恢复密钥。导出密钥应自行保管，换 Mac 时可恢复。此服务没有电子邮件找回机制，遗失密钥后不能凭相同昵称找回身份。

## 两条联机路径

| 路径 | 玩家需要什么 | 对端启动器 |
| --- | --- | --- |
| 普通服务器 / Sakura TCP 地址 | 可达地址；Sakura 房主需要自己的访问密钥、可用节点及额度 | 任何支持标准 Minecraft 多人游戏的启动器 |
| Terracotta / EasyTier 房间 | 房主在游戏中开放局域网；模块按需下载并校验官方 SHA256 | 支持陶瓦的启动器，或在其他启动器旁运行独立陶瓦客户端 |

MC Harbor 自行管理官方 macOS 陶瓦进程，无需安装 LaunchAgent 或系统服务，不要求管理员权限；控制端口只监听回环地址。复用已经运行的核心前检查状态，拒绝接管已有房间。退出时重置自己的房间，并只终止自己创建的核心进程。公共 P2P 节点由社区提供；NAT、网络质量、节点可用性仍影响连接，不能承诺所有网络无条件打通。

Sakura 访问密钥只在本机钥匙串中，运行配置使用私有文件权限，停止时删除；内置 frpc 来自官方发布并校验大小与 MD5。不会在 App、GitHub 或公开好友服务中嵌入作者的 Sakura 密钥。好友服务器只传递邀请，不中转 Minecraft 游戏流量，也不能替代认证或解决不兼容模组。

## 自建仅供有需要的维护者

`social-cloud` 提供 Workers 配置、D1 表和 SQLite Durable Objects 迁移。更换 Cloudflare 账号时须创建自己的 D1、更新数据库 ID，再部署自己的服务；不要把作者账号的 OAuth 凭据放入配置。`social-server/server.py` 是 Python 标准库版本，默认仅回环监听，公网须自行配置 HTTPS 反向代理，聊天使用安全刷新回退。自建服务中的身份不与公共服务自动互通。
