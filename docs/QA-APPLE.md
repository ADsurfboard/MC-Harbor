- 本机 Apple 芯片、macOS 27：原生 ARM64 应用及内置 Java，严格代码签名检查通过；保留系统玻璃、四份欢迎语音及界面音效素材。
- 隔离游戏库、直连网络、Minecraft 1.20.1：国内镜像获取 Forge、Fabric、NeoForge 列表；实际安装 Fabric 0.20.1 和 Forge 47.4.28 成功。

- Dock 恢复与弹窗已在隔离测试环境验证窗口关闭后重新激活；不同系统版本和用户环境仍可能有差异。
- 自动化覆盖不能证明所有游戏版本、网络环境及第三方服务都可用。遇到问题请提供脱敏日志，通过 GitHub Issues 反馈。

## 1.6.0 验证记录

隔离后端检查包含内容白名单导出、未知分类拒绝、归档私有数据排除，以及仅停止指定 Process、不停止旁路进程。中文搜索加载 HMCL 同款内置名称库，简介支持 MCIM 现成译文及国内翻译。新增模组夹持久化、去重、改名改色和快捷应用检查。锁屏期间无法完成鼠标操作验收，原生离屏渲染只用于检查布局，不能视为真实磨砂材质目视验收。最终 Actions 与发行包哈希见 Release。

1.6.0 快捷方式补充：独立 `.app` 将已登记、带有效期的请求写入本机私有收件目录；启动器启动时接收，运行期间监听。比较游戏库前统一两端路径，兼容 macOS 的 `/private` 等价路径。`tools/check-instance-shortcut.py` 使用真实发布客户端和快捷组件测试冷启动、后台再次调用；只替换游戏 JVM 为隔离协议记录器，不表示实际游戏会话验收。离线发现回归增至 97 项，覆盖私有权限、过期 / 无效请求拒绝、单次消费与文件监听。

## 1.6.1 验证范围

中文搜索与列表、简介等待与失败状态、翻译并发和缓存、原文与占位符保护均使用隔离数据检查。真实 Swift 协调器与内置 Java 测试模组语言、KubeJS、FTB 章节和存档数据包的完整流水线；在线回归另外直连国内服务。模组夹双色取色、透明像素处理、原图解码复用与深浅外观的离屏预览单独验证。

后台性能的相同数据五轮比较见 PERFORMANCE-1.6.1.md；不代表 FPS 或所有规模的耗时。原生 Apple / Intel Actions 和发行 ZIP 的签名、解包与公开下载校验见 Release。离屏预览不等同于实际鼠标操作与原生材质的完整实机目视验收。
