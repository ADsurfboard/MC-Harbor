# 设计约定

真实 WinHarbor SwiftUI / AppKit 基础，系统 Liquid Glass 采样背景；Metal 只画大面板静态光学边缘，按钮采用 SwiftUI 边缘，保留可访问标签，避免每个按钮建立 Metal 视图。

默认生态绿 #29825B，调色盘联动主按钮、选中态、强调图标与流体颜色；深色 #0C110E、抬升面 #1D2521。系统中文字体，大标题配小元信息；升级不重置用户颜色、壁纸和参数。

通透度 −1…+1 在界面显示 −100…+100，映射材质 0…1。最低实底磨砂，最高通透，系统减少透明度优先。三层叠片始终磨砂，先做二维投影曲线再应用玻璃，避免三维背景采样产生断线。

1.5.3 已移除按钮、卡片与弹窗的彩虹角，以及 Metal 描边和相关开关。主题范围可逐项选择默认色、主题色、反色或自定义色；反色支持自动黑白、RGB 反色、色相互补和自定义，并可调亮度、饱和度。默认对比度保护会调整文字明暗。玻璃、三层叠片与其他动画保留。

实例管理统一大玻璃弹层：顶部版本 / 加载器、启动、更多动作，下设模组 / 资源包 / 光影 / 存档 / 截图 / 日志 / 设置。进出共享 0.48 秒弹簧过渡，底层模糊与缩放随展示状态恢复，嵌套下载同一材质。

欢迎默认 4.8 秒，220 粒子只在欢迎期间刷新，可跳过。流体使用三个柔化径向渐变层，Core Animation 缓慢位移与拉伸，后台 / 低电量 / 减少动态效果时停止运动。

JDSherbert FREE 包原生立体声仅裁静音并转 PCM；焦点 / 按下 / 导航 / 打开 / 关闭 / 启动 / 完成 / 错误均映射，音量与总开关可调，焦点声音节流。欢迎语音单独控制。

品牌共用 imagegen 生成的黑色磨砂底与浅色 H 折带图标，缩小整个图标占位并增加留白，H 保持原始相对比例，去除图标上的亮边和色散；实例仍保留 HMCL 原加载器图。账号采用 Minecraft 皮肤头部，右侧用开源 skinview3d 展示真实角色，默认静止、拖动时按需绘制。旋转 / 行走只在页面活动且允许动态效果时刷新。
