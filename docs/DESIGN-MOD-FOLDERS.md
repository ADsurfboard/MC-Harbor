# Mod folder material reference

Reference: https://x.com/insporadesign/status/2118223952765911533 — Inspora, credited to @damienghader, published 2026-11-05. Re-inspected in the browser on 2026-11-12. Firecrawl retrieved the post text; its X provider does not support branding or screenshot formats, so the visible video frames were inspected directly in the browser. Original CSS / shader values were not available.

Observed: separate rear sleeve and short front pocket; thumbnails remain visible above the mouth and transmit soft coloured shapes through the pocket; the light edge is directional, not an equally bright perimeter; small contact shadows separate overlapping layers. Hover spreads / lifts the documents and opens the front pocket independently. Pink, neutral and dark examples retain the same optical treatment.

Implementation choices (estimates adapted to SwiftUI, not extracted source values): a 200 × 141 pt rear shell, a 210 × 112 pt pocket and 154 × 110 pt document cards. The pocket transmits an 11 pt softened rendering of the same cached icon textures. It composes the frosted film directly instead of projecting native backdrop-effect subviews in 3D; the main app retains its native glass materials. Tint is a 7.5–12% overlay, with neutral light / dark gradients; only the mouth receives a narrow fading highlight. The front opening is projected with an animated top taper / mouth depth, anchored along its lower edge; the rear shell and documents move independently. Geometry keeps clipping and labels on the same plane on older systems, without depending on native backdrop views inside a 3D transform. Existing 0.44 s spring and reduced-motion behavior are retained.

No full perimeter stroke, rainbow fringe, simulated ray tracing or per-frame network request. Only the leaf document Canvas animates; shell geometry, titles and artwork remain independent of its clock. At most three source cards feed the clear and softened layers; decoded icons and remote fetches are shared. Missing icons on actual entries use the bundled Minecraft panorama. Empty folders contain no placeholder document. The foreground panel remains an ordinary readable, selectable mod list. Names and tint remain configurable.

Verification must include light / dark and several tint colours, empty / populated folders, hover and opening the foreground panel. Offscreen captures establish geometry only; native material and interaction require the actual window. This is an adaptation, not a claim of exact original shader equivalence.


## Fluid document underlay

The original mod icon remains the foreground. Each icon is decoded once, downsampled in sRGB and analysed off the main thread with alpha-weighted two-cluster colour extraction. Transparent pixels do not contaminate the palette. PNG gaps reveal a semi-transparent field made exclusively from those two core colours, animated with coherent warping and an actual Gaussian blur Canvas filter. A monochrome icon stays monochrome. No fixed rainbow or ASCII mode is used. Boundary / alpha feathering joins the unchanged original image to its underlay. The leaf Canvas updates at up to 60 fps only while visible and active; reduced motion freezes it. Hover / shell animation remains independent. No image decode, colour extraction, font layout or network request occurs per frame. Empty folders render no document or underlay.
