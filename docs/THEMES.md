# 主题范围与反色

“设置 → 外观 → 主题范围与反色”提供十类独立配色：主要按钮背景、按钮文字与图标、选中状态与控件、界面图标、强调文字、主要文字、辅助文字、玻璃卡片底色、卡片与按钮边框、欢迎动画与流体配色。

每类可以选择默认色、主题色、反色或单独的自定义色。可以恢复默认范围，也可以一键让全界面跟随主题。原始模组图标、实例图片、头像与皮肤保留原图，错误/成功等状态图标保留语义颜色。

反色支持自动黑白对比色、RGB 通道反转、色相互补、自定义四种方式。可调反色亮度和饱和度；将需要使用反色的界面类别选为“反色”。另可调整卡片染色与边框强度。所有设置保存到本机偏好。

自动保护文字对比度默认开启：在标准深浅玻璃参考底色上，将强调文字与按钮标签调整到至少 4.5:1；背景图片内容仍可能影响局部效果。关闭保护后按指定原色显示，便于精确创作。自定义颜色以标准 sRGB 保存，避免重启后偏色。

彩虹角已完全移除，相关开关、按钮描边和 Metal 绘制代码不再包含在此版本中。
